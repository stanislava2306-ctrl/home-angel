# Монтаж ролика «свеча — градусник дома»

Вертикальный Reels 1080×1920, 58.8 с. Тот же движок, что и в `../montazh-son`:
наложение рисуется в HTML, рендерится покадрово Chromium с прозрачным фоном
и сводится с исходным видео одним проходом ffmpeg. Звук оригинальный.

## Что в монтаже

- заголовок в начале: «ДОМА ТЯЖЕЛО ДЫШАТЬ? ЭТО НЕ УСТАЛОСТЬ»;
- пословные субтитры-плашки (одно слово в кадре) там, где нет крупных плашек;
- три пункта проверки — нумерованные плашки 01–03;
- финальный чек-лист действий: строки появляются на своих словах;
- b-roll полупрозрачный: свеча с живым пламенем и дымом (в хуке — гаснет),
  соль, сыплющаяся в угол, распахивающееся окно с потоками воздуха.

## Файлы

| что | где |

## Как пересобрать

```bash
python3 align2.py src/ishodnik.mp4 tekst/scenariy.txt tekst/words.json
python3 render_montazh.py --shots 1.4,5,28,33,47     # кадры на проверку
python3 render_montazh.py --video --out СВЕЧА-монтаж-мастер.mp4
```

После правки `tekst/words.json` пересоберите `grafika/slova.js`:
`[[слово, начало, конец, № фразы], …]`.

## Тайминги: пословное выравнивание без whisper

Whisper в облачной сессии недоступен (hugging face и прочие хосты с моделями
закрыты сетевой политикой, доступны только pypi и npm), поэтому `align2.py`
кладёт известный сценарий на реальный звук в три шага:

1. паузы ≥0.2 с → динамикой расставляются границы предложений по настоящим паузам;
2. в полосе 300–3400 Гц ищутся **слоговые ядра** — локальные максимумы огибающей
   (один пик ≈ один гласный);
3. внутри фразы ожидаемые слоги слов сопоставляются с найденными ядрами
   (динамика с пропусками), начало слова = его первое ядро минус 55 мс на согласную.

На этом ролике: 264 слога в сценарии, 278 найденных ядер, **96.8 % слогов сели
на реальное ядро**. Это и даёт пословный синхрон без распознавания речи.
Если прогнать `transcribe.py` на машине с whisper — формат `words.json` тот же.
