# Монтаж ролика «сон с четверга на пятницу»

Вертикальный Reels 1080×1920, 81 с. Наложение (плашки + полупрозрачный b-roll) рисуется
в HTML, рендерится покадрово через Chromium с прозрачным фоном и сводится с исходным
видео одним проходом ffmpeg. Звук — оригинальный, не тронут.

## Файлы

| что | где |
|---|---|
| исходник | `src/ishodnik.mp4` |
| сценарий (по фразе на строку) | `tekst/scenariy.txt` |
| тайминги слов и фраз | `tekst/words.json` |
| выравнивание текста по звуку | `align.py` |
| вёрстка наложения (движок) | `grafika/montazh.html` |
| содержание сцен и времена | `grafika/scenes.js` |
| рендер и сведение | `render_montazh.py` |
| готовый ролик | `СОН-ЧЕТВЕРГ-монтаж.mp4` |

## Как пересобрать

```bash
python3 align.py src/ishodnik.mp4 tekst/scenariy.txt tekst/words.json   # тайминги
python3 render_montazh.py --shots 1.2,19,45,58,72                       # кадры на проверку
python3 render_montazh.py --video --out СОН-ЧЕТВЕРГ-монтаж.mp4          # весь ролик
```

Правки текста и времён — только в `grafika/scenes.js`. Предпросмотр без рендера:
открыть `grafika/montazh.html` в браузере (пробел — пауза, ←/→ ±1 с, `?t=28` — стоп-кадр).
Там видно только наложение, без видео героини.

## Тайминги: чем они получены

Whisper в этой облачной сессии поставить не удалось — hugging face и остальные хосты
с моделями закрыты сетевой политикой, доступны только pypi и npm. Поэтому `align.py`
кладёт известный сценарий на реальный звук: строит RMS-огибающую 10 мс, находит все
паузы ≥0.2 с и динамическим программированием расставляет границы предложений по
настоящим паузам так, чтобы длительность каждой фразы была близка к её слоговой норме.
22 границы из 24 сели на реальные паузы; слова внутри фразы делятся по слогам.

Точность: фразы — до ±0.1 с (сидят на паузах), слова внутри фразы — около ±0.3 с.
Для плашек этого достаточно. Если нужен пословный синхрон под кинетическую типографику,
на своей машине:

```bash
python3 ~/.claude/skills/reels-montazh-pro/scripts/transcribe.py src/ishodnik.mp4 \
        --out tekst/words.json
```

и пересобрать — формат `words.json` тот же.
